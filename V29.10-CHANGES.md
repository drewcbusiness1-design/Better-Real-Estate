# Better Real Estate v29.10 — Authorized MLS Intelligence Layer

- Added a provider-neutral authorized MLS / RESO Web API evidence adapter. No Zillow/MLS website scraping.
- Supports one feed through `MLS_RESO_*` environment variables or multiple authorized feeds through `MLS_RESO_SOURCES_JSON`.
- Deal Builder now researches configured feeds before AI analysis, fills missing subject facts (beds, baths, living area, year built, property type) from sourced evidence, and passes that evidence to the AI instead of asking it to invent facts.
- Automatically retrieves nearby closed-sale candidates from configured MLS feeds, deduplicates them, calculates distance where coordinates are available, and preloads them into the deterministic comp engine.
- Property Evidence card exposes source/provenance, source update time, source failures, and whether live feeds are actually configured.
- If no authorized feed is configured, Better says so plainly and continues with the existing preliminary AI + manual verified-comp workflow. It never pretends it searched MLS/Zillow.
- Tutorial v40 explains automatic property evidence.
- No paid provider, API credential, Zillow scraping, or unapproved dependency was added.
