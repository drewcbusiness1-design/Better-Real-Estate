# Better Real Estate v29.30 — Live Mascot Character

## What changed
- Replaced the header mascot experience with a true multi-pose live character system.
- Added multiple optimized mascot pose assets (idle, wave, point, welcome, celebrate, excited).
- Better Guide mascot now changes state contextually instead of feeling like one picture with transforms.
- Added contextual speech-bubble hints tied to the current Better workflow.
- Reused the live mascot across the header trigger, Better Guide panel, tutorials, and free course.
- Kept the prior layered rig code in place for regression safety while upgrading the primary UX.

## UX intent
- Keep the mascot to the right of Settings.
- Stop the “single static pose” feeling.
- Make the mascot feel like a living helper that can greet, guide, celebrate, and teach.
