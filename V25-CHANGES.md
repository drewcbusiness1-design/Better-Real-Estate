# Better Real Estate v25 — Professional Operations

Built from the approved professional-homepage release and preserves the existing Better Real Estate feature set.

## Restored / requested
- Replaced improvised text-symbol navigation with consistent outline SVG icons for Feed, Shop, Post, Network, Profile, Messages, Boost, Wallet and theme.
- Admin can grant or remove account verification directly from Admin, and from Membership Grants.
- Members can choose whether their current membership level is displayed publicly on their profile.

## Deal workflow expansion
- Auto AI Deal Builder: the existing smart/AI deal importer is now presented as a first-class workflow for turning rough deal text into structured listing fields.
- Better Dispo remains intact: buyer matching, matched-buyer notifications, Facebook/Instagram/SMS/email copy, public deal link, printable flyer, story card, sharing and listing freshness.
- Private Deal Command Center on owned listings: stage, next action, task checklist and private operating notes.
- Showing Scheduler: listing owners publish access windows; signed-in buyers can reserve available times.
- Deal Rescue: listing analytics now surface contextual next-action suggestions from actual views, saves, unlocks and offers.
- Demand Insights: ranked public buy-box demand by market, property type and strategy, with clear language that counts are demand signals rather than guaranteed transactions.
- Optional “Open to JV” flag on new property listings.

## QA
- Existing automated regression suite passes.
- Added a dedicated professional-operations wiring test for the new workflows.
- JavaScript syntax checks pass for client and server.
- Responsive CSS added for admin verification, deal rooms, showings, demand insights and membership badges.
