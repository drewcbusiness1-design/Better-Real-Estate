# Better Real Estate v29.24 — Conservative Site Cleanup RC

This release is intentionally surgical. Existing approved surfaces are left alone unless a concrete defect, performance wait, spacing/alignment problem, or invalid theme token was found.

## Navigation and performance
- Settings now renders synchronously from the account state already loaded into the client; opening Settings does not wait on a secondary request.
- Universal Search paints its usable search surface immediately and hydrates the first result set in-place rather than blocking route presentation.
- v29.22/v29.23 Network non-blocking search behavior and reduced polling/cost protections are preserved.

## Property sharing — connectivity first
- Property Share now opens a ready-to-post professional property promotion instead of handing the user a bare app link.
- Copy is generated only from fields actually present on the listing; missing ARV, repairs, beds/baths/square footage, type or deadline are omitted rather than invented.
- No emoji are inserted into the prepared property post.
- The prepared post carries a direct property deep link and explicitly invites interested buyers to view the deal and connect through Better Real Estate.
- Copy-caption, native share sheet, Facebook, LinkedIn, X, and direct-link actions remain available. Where a destination cannot accept prefilled copy, Better copies the prepared post before opening it.

## Conservative visual cleanup
- Added missing compatibility theme aliases used by older operating-network/admin components so borders, secondary panels, muted text, accent lines and danger states resolve consistently in both themes.
- Added only isolated spacing/form rhythm rules and the new share surface. Existing card shapes, photo layout, typography system, navigation and approved feature layouts are otherwise unchanged.
- Share modal is touch-scrollable, safe-area aware, responsive, and dark-mode compatible through existing design tokens.

## Preserved release protections
- v29.20 truthful buyer matching, v29.21 detail stability, v29.22 cost reductions and v29.23 centered property facts / Property Access / admin deletion remain in place.
- No provider, dependency or architecture substitution.
