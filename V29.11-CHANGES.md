# Better Real Estate v29.11 — Live Property + Web Intelligence

- Connected the server-side Regrid token to Regrid's live US parcel address endpoint.
- Normalizes county/parcel facts including bedrooms, bathrooms, year built, parcel/lot data, sale data and other available fields without inventing missing values.
- Added public-web property research through the existing OpenAI Responses API web-search tool. It researches exact-address facts, sale/listing history, recent sold comps and active/pending market context without direct site scraping or bypassing access controls.
- Preserves evidence sources, retrieval times, source conflicts and research errors.
- Keeps authorized RESO/MLS adapters from v29.10 and cross-references MLS, Regrid and public-web evidence.
- Sold comps are deduplicated and passed through Better's deterministic similarity/outlier engine. When at least two credible researched sold comps survive selection, the comp-supported calculation becomes the working ARV instead of the address-only AI estimate.
- Active/pending listings remain market context only and never count as closed comps.
- Deal Builder now tells the user that it is researching records, authorized MLS sources, the public web and sold comps.
- No Zillow/MLS website scraper was added. Public web search may discover publicly indexed listing pages, but Better does not bypass provider restrictions; licensed feeds remain the path for authoritative MLS data.
