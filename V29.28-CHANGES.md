# Better Real Estate v29.28 — Interactive Mascot Polish

## What changed
- Removed the visible `Guide` pill label from the top bar. The Better golden retriever is now the control itself.
- Removed the stacked/double-circle treatment and gave Settings + mascot independent spacing so they cannot overlap.
- Added a lightweight transparent cutout derived from the existing approved mascot artwork. No new mascot was generated and no AI-generated Better logo was introduced.
- Added restrained Better-style mascot behavior: idle presence, hover/focus acknowledgement, tap/open reaction, panel nod, tutorial motion and course-completion celebration.
- The mascot uses CSS transforms only; there are no timers that poll the server, no new APIs, no new dependencies and no background jobs.
- Reduced-motion preferences and the existing Better Guide animation setting disable mascot motion.
- Updated the tutorial/What's New flow so existing users can discover that the mascot itself is now interactive.
- Kept the v29.27 Better Guide panel, help search, course, progress, permissions and support behavior intact.

## Brand safety
- `public/better-guide-mascot-cutout.webp` is a non-generative background-removal derivative of the already approved `better-guide-mascot.webp` source.
- The exact canonical Better logo remains `public/better-guide-logo.png`; the mascot artwork itself does not contain a recreated Better logo.
