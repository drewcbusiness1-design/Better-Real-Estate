# Better Real Estate v26.1 — Auth, Membership Usage & Leaderboard Polish

## Critical regression fixed
- AI Deal Builder and Buyer CRM are now explicitly registered in the authenticated view renderer. In v26 the routes existed, but the renderer map omitted them, causing navigation to fall back to the public homepage and look like the user had been signed out.
- Session/logout behavior itself was not changed; these tools now stay inside the authenticated workspace.

## Deal Builder membership usage
- Free/trial: one successful address analysis during the free trial.
- Pro: five successful new property analyses per UTC day.
- Platinum: unlimited.
- Wholesale Teams: unlimited.
- Admin: unlimited.
- Usage is enforced server-side, not only in the UI.
- Failed property-intelligence calls do not consume usage.
- Editing assumptions, selecting comps, using the calculator, and reviewing results do not consume another analysis.
- The Deal Builder shows the member's current allowance before analysis and updates it after a successful run.

## Leaderboard redesign
- Unified typography with the rest of the application.
- Points are aligned to the far right of each member row.
- Added a polished explanation panel.
- Current point rules are stated in-product: each admin-verified closed deal awards 100 points to the verified seller and 100 to the verified buyer.
- Badge thresholds are explained: Bronze 100+, Silver 200+, Gold 500+.
- Monthly vs all-time behavior and potential admin-awarded membership prizes are explained.

## QA
- Full pre-existing test suite passes.
- Added v26.1 regression tests for authenticated view registration, membership quota enforcement, no quota charge on failed analysis, leaderboard point explanation, typography, and point alignment.
- JavaScript syntax checks pass.
