# Better Real Estate v27 — Operating Network

v27 turns the existing social marketplace into a more connected real-estate operating workspace while preserving the confirmed-good v26.5 baseline.

## Major additions
- Admin Active Now + 24h / 7d / 30d / custom activity analytics and user inspector
- Investment Markets profile preferences and smarter For You ranking
- Separate For You / Following feeds and Not interested feedback
- Liked = watched by default, with independent change-notification toggle
- Saved Searches + Deal Alerts
- Advanced structured Buy Boxes
- Universal search across properties, people, companies, buyers and markets
- Deal Pipeline, Deal Rooms, structured Offer Builder and permission-aware Document Vault
- Deal Calendar with manual and automatic deadlines
- Expanded seller listing analytics and credibility/activity signals
- Expanded Team operations: shared CRM/pipeline, assignments, notes, activity and analytics
- Command Center, Recently Viewed, Quick Create and Market Hubs
- Profile/navigation organization upgrades
- Tutorial v29 with membership-aware onboarding and focused v27 What's New guidance

## No new third-party dependency
No unapproved external API or paid service was introduced for these features.
