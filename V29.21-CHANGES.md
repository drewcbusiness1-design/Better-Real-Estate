# v29.21 — Instant Property Details

- Property cards now hand their already-loaded, privacy-gated listing data into the detail route so the property photo, location/address state, price and basic specs appear immediately after tapping **View details**.
- The complete listing response hydrates the preview in place. Slow network/database work no longer leaves the feed sitting on screen with no visible response.
- Added stale-render protection so a delayed property response cannot overwrite a newer route after the user navigates away.
- Removed view-analytics persistence from the blocking `GET /api/listings/:id` path.
- Added a dedicated non-blocking property-view endpoint and a single-record database append helper. In production Postgres, recording one view now writes one view record instead of saving every application collection.
- Buyer-match truth protections from v29.20 are preserved.
- Added v29.21 regression coverage and updated version assertions. Full automated suite passes through v29.21.
