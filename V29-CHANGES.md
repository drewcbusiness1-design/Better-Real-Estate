# Better Real Estate v29 — Transaction OS + Affiliate Engine

Built directly from v28 Growth Engine. No approved v28/v27 functionality is intentionally removed.

## Growth economics
- Standard referral reward is now $1 in non-withdrawable Better Credit per qualifying first purchase, with a separate Better Credit balance.
- Better Credit cannot be withdrawn as cash and can be applied to membership checkout. Stripe receives a one-time Better Credit discount while future subscription renewals remain at the normal plan price.
- Quick Options no longer duplicates permanent Search or Messages icons; it is a membership/role-aware tool launcher.
- Literal ⚡ emoji removed from Boost copy; the approved Boost icon remains untouched.

## Affiliate program
- Registered users may apply; Admin must approve before an affiliate link activates.
- Initial commission: 30% of eligible membership revenue.
- Versioned in-platform terms must be affirmatively accepted. A future terms/rate version pauses new affiliate earning until accepted.
- 14-day pending hold, server-side attribution/idempotency, self/duplicate protections, refund/chargeback reversals, commission history and Admin approval/performance controls.
- Affiliate cash earnings are separate from Better Credit.
- Withdrawals use the project's existing Stripe Connect architecture. Better Real Estate never stores raw bank/card credentials.

## Transaction OS
- Transaction Hub with Relationship CRM, follow-up reminders, deal tasks, public Deal Intake Links, buyer credential references, service-provider discovery, closing outcomes/profit tracking and CSV exports.
- Deal Rooms gain transaction tools, offer comparison, collaborative comp boards and chronological activity.
- Backend support for file requests, property-level collaborators, deal outcomes, explainable buyer matching and service-provider discovery.
- Public investor profile link copy action.
- Granular notification-category controls in Settings.
- Desktop Cmd/Ctrl+K command palette for fast tool navigation.

## Tutorial
- Tutorial version 33.
- Existing users receive v33 What's New steps for Transaction Hub and Affiliate Program.
- All inherited tutorial behavior remains: Back + Next/Finish, separate Skip Entire Tour, no Skip This Step, real live-target spotlighting and membership-aware access.

## Deferred
- Video calling/conferencing remains intentionally deferred to its own future project.
