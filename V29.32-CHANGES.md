# Better Real Estate v29.32 — Articulated Header Mascot Rebuild

This release replaces the previous mascot implementation rather than patching it.

- Removed the previous raised-paw rig from the active app path.
- Built a new articulated character from a neutralized source construction with separate torso, head, muzzle/expression, ears, left/right arms, left/right paws, and tail.
- The character is physically anchored to a permanent header stage beside Settings.
- Pointer input feeds a slow damped gaze target instead of directly moving joints.
- Idle movement uses short sequences with long pauses so the character settles naturally.
- Tutorial pointing selects the left or right arm according to the target location.
- Click/open/course reactions return smoothly to the resting position.
- No speech bubble and no slideshow/pose swapping system.
- No new runtime API calls, polling, dependencies, or generated branding.
