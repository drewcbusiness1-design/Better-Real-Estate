# v29.27 — Better Guide + Learn Wholesaling

## Better Guide
- Adds the Better golden-retriever mascot as a restrained help control immediately to the right of Settings.
- Opens a theme-matched, keyboard-accessible help panel with contextual product guidance, help search, tutorial replay, support routing and next-step guidance.
- Core help stays free. Paid memberships receive an additional advanced-guidance area without locking basic product help or education.
- No AI request is required for ordinary help, course content, tutorial guidance or deterministic next-step suggestions.

## Learn Wholesaling — free
- Adds a 12-module beginner wholesaling course centered on doing the work inside Better Real Estate.
- Modules connect the concepts directly to Better tools: Settings/markets, Deal Intake, Deal Pipeline, Deal Calendar, Deal Intelligence, Network, Buy Boxes, Buyer CRM, Better Dispo, Deal Rooms, Transaction Hub and Command Center.
- Each module includes a knowledge check. Progress, passed checks and resume position persist in the user’s existing settings JSON; no database migration is required.
- Education includes state/jurisdiction and professional-advice guardrails rather than presenting one transaction structure as universally legal.

## Tutorial integration
- The Better mascot now visibly guides the existing platform tutorial.
- New-user tutorial offers a direct path into the free course for people who are new to wholesaling.
- Tutorial version advances to 52 and What’s New teaches the Guide and learning experience in the same release.

## Brand + performance
- The canonical Better logo is copied byte-for-byte into `public/better-guide-logo.png` and composited in the UI. No AI-generated/recreated logo ships in the product.
- The mascot base image does not contain a generated logo. The web asset is compressed to a lightweight WebP and the real logo is layered separately.
- No new runtime dependencies, external APIs, polling loops or background jobs were introduced.
