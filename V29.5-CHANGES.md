# Better Real Estate v29.5 — Controlled Demo Accounts

- Admin can explicitly create demo accounts from Admin Command Center.
- Demo accounts can simulate Free, Better Plus, Platinum, or Wholesale Teams access without creating paid billing.
- Demo accounts are permanently excluded from First 100 Founder allocation while marked demo; conversion to real does not retroactively consume a Founder slot.
- Demo accounts are excluded from production user/activity/growth metrics and cannot generate real billing, marketplace purchases, referral rewards, affiliate applications/commissions, or payouts.
- Admin User Inspector clearly labels DEMO accounts and supports Reset demo and Convert to real actions.
- Reset returns the account to a clean presentation/testing state while preserving its login identity and demo designation.
- Tutorial v37 explains Demo Accounts to Admin only.
- All new controls follow Better Real Estate alignment, sizing, responsive, and theme requirements.
