# v29.67 — Land intelligence and organized administration

Full source update from v29.66, including all startup/signup/workspace corrections. Not deployed.

## Current scope
- Admin is grouped into initially collapsed native details sections, with Expand all / Collapse all and per-admin local expansion preferences. Tools and their event handlers stay inside the sections.
- User Inspector has a collapsed row for each member and lazy-loaded profile details. Basic name, username, phone, bio, location and investment-state editing is inside the entry. Changes validate before mutation, reject unsupported fields, require a current profile fingerprint and retain an admin field-change log. Public profile, service business and buying criteria context is displayed. Passwords, auth tokens, private conversations and payment credentials are not returned by the new endpoint.
- Membership grants and access are embedded in each non-admin member entry using the existing grant/extend/replace/revoke handlers and confirmations. Paid, complimentary and founding access summaries and per-user grant history remain distinct. Verification, founding and existing demo/account actions are inside the expanded entry. The historical Membership grants route is retained for old links and existing bulk/leaderboard tools.
- Report an issue / Give feedback and Contact support appear once in a separated footer at the bottom of the dog menu. Other standalone help panels retain these links.
- Land report shows sourced parcel/financial facts (parcel size and number, zoning, road access, utilities, flood zone, taxes, assessed value, prior sale and current price when available), source status and source detail. Acreage, asking price per acre, monthly tax equivalent and researched closed-sale unit prices are calculated from available sourced values. Recorded facts are not labeled verified; conflicts suppress the chosen value.
- Existing public-web research schema/instructions now capture land-specific facts and closed-sale parcel attributes. Returned values must be grounded in actual searched-source excerpts; acre-to-square-foot conversion is checked explicitly. Existing MLS lot/price/sale fields feed the auxiliary evidence resolver. No new provider, research pass or scraping integration is introduced.
- A comparable-based land range is allowed only when exact identity, resolved land type, cross-source parcel number/size/zoning/access/utilities, at least three comparable closed land sales and at least two independent source families qualify. Recent date, known distance, lot-size comparability, land classification, source provenance, duplicate/conflicting price and parcel-field checks and outlier handling apply. Otherwise the range remains withheld and missing requirements are listed. Observed sale unit prices are separately labeled as descriptive, not subject value. It is not a development/residual valuation, appraisal or buildability finding.
- No manual calculator or listing-details inputs are added to AI land results. A Refresh land research button allows updating older cached evidence; research uses existing configured providers and quotas. This implementation does not guarantee that sources have complete parcel information at every address.
- Tutorial version 85 explains grouped admin controls; land help text reflects the researched report. The permanent delivery rule is recorded: every update-file response must include install/test commands AND commit/push commands.
