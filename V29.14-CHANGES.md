# Better Real Estate v29.14 — Property Discovery Reliability

- Fixes a Regrid normalization bug: Regrid address-search responses can place the canonical display address in `properties.headline`; v29.13 only inspected standardized fields, so legitimate parcels could be rejected as unmatched.
- Preserves the Property Truth Gate: one source is evidence, never automatically verified truth; conflicting sources remain withheld.
- Makes public-web research more targeted and bounded for Netlify reliability: exact-address identity first, basic facts first, sold comps second, medium search context, smaller structured output, 15-second hard bound.
- Explicitly prioritizes assessor/public records, broker/MLS-syndicated pages, Realtor.com, Redfin, Homes.com and other reputable sources.
- Does not scrape Zillow or claim direct Zillow lookup without authorized Zillow API/licensing. Zillow URLs surfaced by public web search may be treated as navigation/source-discovery evidence only, consistent with Zillow's published restrictions on automated queries.
- Keeps cached evidence and no-fake-precision behavior from v29.13.
- Adds regression coverage using 503 W Grand Prairie St, Palestine, IL 62451 to ensure Regrid `properties.headline` exact-address matching cannot regress.
